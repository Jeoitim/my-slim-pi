# Web 工具迁移验收

日期：2026-10-20。远端最新 main 与工作区基线均为 82374337ec7a6a8f3815735805b4fadeb89b960b；保留工作区原有审批和通知改动。验证完成后，按用户明确授权安装到 Windows / Linux 各自实际 AgentRoot，保留私密快照并将已有 Exa、Brave、Tavily Key 迁入两端独立私密配置；未修改用户 PATH。Git 提交由外部维护执行，不推送。

## 最终实现

- [pi-web-access](https://github.com/nicobailon/pi-web-access) 稳定版 0.43.0，npm 精确版本与完整依赖锁；直接使用上游预构建入口，共享宿主 SDK。无 Web 专用宿主补丁、私有 SDK 调用或包装工具。
- 原生 web_search、fetch_content、get_search_content。不设置 searchRouting 或 allowedProviders，默认使用上游原生 auto 并保留全部供应商；Parallel MCP、degoog、DuckDuckGo、Keenable 等免 Key 入口仍遵循上游的显式选择规则；保留原生 Fetch 回退及缓存。toolActivation=auto，模型兼容时提供原生 web_enable，否则直接声明三个工具。取消、错误分类和严格 provider 选择均交由上游。
- 关闭 source_check、Curator/摘要、浏览器 Cookie、Git 克隆、GitHub 凭据读取、PDF 落盘、视频及图片附加处理。普通网页免审，敏感参数按四模式处理；PDF 等能力启用后，相关 fetch 与 includeContent 搜索整体取消只读豁免，以覆盖无扩展名 URL、重定向和后台抓取。
- 删除本地统一入口、专用 MCP 桥接、供应商适配器、代理传输及旧测试。mcp.json 默认无服务器，宿主通用 MCP 能力保留。
- 原生私密 web-search.json 管理 Key 和 proxy；Windows DACL，Linux 0600。旧 Key 和实现先备份再迁移/移除；npm 清单与锁文件也纳入配置快照，依赖回退需恢复旧锁后重装。分享导出只采用仓库无密钥模板。

## 工具上下文实测

同一离线 hello，采集真实请求声明；不发送模型请求。单位为 JavaScript 字符串长度，不是 token。没有个人上下文文件；auto 的两种模型路径分别测量。

| Windows 指标 | 迁移前 | auto：首轮完整声明 | auto：延迟激活首轮 |
|---|---:|---:|---:|
| 首轮工具数 | 10 | 12 | 10 |
| 系统提示字符 | 5745 | 5904 | 5679 |
| 工具定义字符 | 8747 | 15778 | 8006 |
| 总字符（含用户消息） | 14524 | 21714 | 13717 |

Linux 对应工具定义字符为 8735 → 15766 / 7994；总字符为 14527 → 21718 / 13721，工具数同为 10 → 12 / 10。

因此，延迟激活首轮的工具定义约减少 8.5%；首轮直接声明三个原生工具的总字符增加 49.5%。延迟激活后会追加完整工具声明，不能把首轮节省当作整段会话的永久节省。未估算 token 或宣称缓存命中率提升。

## 维护与剩余边界

维护复杂度转移到固定上游包；运行依赖数量增加，不能据此声称减少依赖。后续升级需重审上游参数及副作用，复验动态激活、SSRF、PDF/视频/认证和跨平台代理行为。保留插件的原生安全检查，不宣称操作系统隔离。

默认关闭的附加能力需由用户在外部配置中启用、重建并重启；启用 PDF 后普通抓取也可能需要审批。代理使用上游 curl，需可执行的 curl；Windows 静态代理排除列表不自动转换，额外排除规则使用 NO_PROXY，PAC 不执行。

默认快照可能含搜索 Key 和认证代理，必须私密保管。回退恢复旧配置、源码及 npm 锁后，按锁重装并重建；单独 Restore 不回滚依赖。真实供应商额度/限流、付费调用和浏览器 UI 仍是未进行的在线验收范围。
