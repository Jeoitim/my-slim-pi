# 工具声明优化

日期：2026-10-22。Pi 1.3.0；锁定依赖、默认工具和技能加载策略不变。已在 Windows `.local/language-win` 与 WSL2 Linux 原生仓库 `.local/language-linux` 的独立安装验证，并按用户授权部署到两端各自实际运行目录。

## 实测

本地模拟 provider 采集首轮真实请求声明，不发送模型请求；MCP 服务器连接禁用，提示使用同一 `inspect-project`，工作目录为各自安装内的空白测试目录，不加载个人上下文文件。单位为 JavaScript 字符串长度，不是 token。

| 首轮工具定义字符数 | 优化前 | 优化后 | 减少 |
| --- | ---: | ---: | ---: |
| Windows，动态模型，16 个工具 | 15,808 | 12,896 | 18.4% |
| Linux，动态模型，16 个工具 | 15,796 | 12,884 | 18.4% |
| Windows，兼容回退，18 个工具 | 23,580 | 20,605 | 12.6% |
| Linux，兼容回退，18 个工具 | 23,568 | 20,593 | 12.6% |

`ask_user` 单项声明从 4,213 降到 2,786 字符，减少 33.9%；删除重复问答 guideline 另减少系统规则。两端工具名称和数量均不变。两条路径的差别仍由上游 Web 的模型兼容性判断决定；后续激活 Web 会追加完整 schema，首轮减少不能当作整段会话永久节省。

复测使用 `customization/checks/profile-prompt.mjs --prompt=inspect-project --cwd=<空白测试目录> --no-context-files`；加 `--dynamic-model` 采样动态路径。分别设置各平台原生独立安装的 `PI_CODING_AGENT_DIR`，使用该平台的 Node。脚本只采集声明，不检验真实模型的工具选择质量，也不推算 token、费用或缓存命中率。

## 范围与边界

- 现有 memory 工具的 `prepareLoadout` hook 提供简短描述，不改变声明数量、工具注册、执行或授权。使用稳定文本，只在更短时替换。
- ask_user 保留所有原有字段、界面控制和用户偏好，仅缩短说明，继续接管 timeout。schema 的类型、必填项、枚举、批量数量限制与非枚举 TypeBox 校验元数据均保留。
- 清除 replace/grep 对当前已隐藏编辑工具的使用建议；保留锚点、分页、截断、正则限制和撤销条件。
- read 的完整锚点说明、权限/维护工具说明和 fetch_content 根据配置生成的能力说明保持原样。Web 参数 schema 仍由原生包维护，没有为了更小数字接管整个 Web 插件的注册或修改依赖。
- 技能描述沿用现有分层索引，没有新增 skill_search、tool_search、按关键词切换或每轮裁剪。

回退只需恢复本次 suite 源码并通过现有构建入口重建、检查和重载；无需更换依赖锁或迁移运行数据。

## 本机部署

两端通过各自标准安装器更新实际 `~/.pi/agent`，分别建立更新前私密备份、按锁文件安装原生依赖、重建四个启动入口和任务代理产物，并通过离线启动检查；实际运行目录未用作回归测试夹具。

逐端核对 70 个公共源码文件，与本次分发哈希全部一致；`policyIntegrity`、`buildReady` 和扩展启动均通过。认证与模型文件、信任、平台提示词、搜索凭据和代理、默认工具、主题、后台模型及委派设置的更新前后指纹一致；未调整用户 PATH 或 Shell 配置。脱敏验收报告位于各安装的 `customization/reports/tool-declarations-deployment-20261022.json`。正在运行的 Pi 会话需要 `/reload` 或重启后加载新声明。
